隐私政策

更新日期：2026 年 10 月 26 日

旅序（英文名 TripVellum）由吴天宇（个人开发者）提供，帮助你在当前 iPhone 整理出行。无需注册旅序账户，基础功能无需 AI API Key。自动扫描是由你自行配置的可选功能。

保存在本机的内容

行程、清单、时间轴、账本和来源资料保存在当前 iPhone。旅序不提供行程云同步。系统整机备份是否包含这些资料，取决于你的 iPhone 备份设置。

可选自动扫描与 DeepSeek

配置 API Key 时，会向 DeepSeek 发送密钥和不含个人资料的验证样例。首次发送行程资料前会单独征求你的同意。图片与 PDF 在本机提取文字；所选文字、PDF 页码、来源日期（如有），以及当前时间、设备时区、语言和地区、行程起止日期与默认币种，会直接发送给 DeepSeek，用于整理结构化行程。原始图片、PDF 和现有时间轴不会发送。资料超过字符上限时只发送开头部分，并提示本次未处理全部内容。文字可能包含姓名、联系方式、预订号等个人信息，发送前不会自动脱敏；请只选择你有权且愿意交给服务商处理的资料。DeepSeek 的处理、保留和计费适用其独立政策与条款；旅序无法代为删除其服务端资料。

AI 服务的处理地点

DeepSeek 的公开隐私政策说明相关个人信息在中国处理和存储；从其他国家或地区使用自动扫描时，选定资料的文字仍交由该服务商处理。其处理、保留与后续使用受独立政策及适用条款约束，旅序不承诺普通 API 零保留或不用于模型优化。请先阅读下方服务商政策，并只选择有权且愿意交给服务商处理的资料。

系统年龄信息与自动扫描

在支持的系统上，旅序会向 Apple 查询是否适用年龄相关要求，需要时通过系统界面获取年龄范围。旅序只在本机内存中使用据此形成的可用性状态，不持久化原始范围，不将年龄检查结果写入行程、来源资料、日志、诊断报告或发给 DeepSeek；年龄检查不会要求你向旅序提供精确生日或证件。本版本暂不向系统已识别的未成年人开放自动扫描；需要的检查未能完成时会暂停 AI 请求，并提供重试。本地功能与现有已购权益不因此被删除或清除，购买相关的系统授权由 Apple 处理。年龄相关能力受系统版本及 Apple 提供的信息影响。

密钥与网络安全

API Key 仅存于当前 iPhone 的本机钥匙串，不参与同步。AI 请求只连接固定的 DeepSeek HTTPS 服务；旅序不托管或转发请求，不将密钥、输入正文或完整模型响应写入日志。

来源资料与删除

成功新增或更新安排的来源资料在本机保留；即使本次只识别了部分文字，原始图片、PDF、TXT 和粘贴文字仍保持完整。PDF 记录本次处理的页面，OCR 中间文字不另存或建立索引。删除来源资料会移除所有引用，但保留安排；删除最后一个关联条目、删除行程或撤销后，会清理失去引用的资料。时间轴文字与 PDF 分享不包含来源资料。

权限与分析

仅在选择图像来源时使用你授权的照片或相机，在选择文件时读取所选文件。取消或拒绝权限后仍可使用手动功能。旅序不使用第三方行为分析 SDK，也不进行广告跟踪；系统诊断由你的 iPhone 设置控制。

独立的汇率服务

账本按需连接 Frankfurter（api.frankfurter.dev）获取参考汇率，请求参数包含币种和所需日期，不发送账目标题、参与人、付款凭证或 AI 密钥。网络连接本身会向接收方提供 IP 地址等通信信息；Frankfurter 公布的隐私说明称其不收集或记录个人数据、IP 地址或请求 URL，仅查看聚合流量统计。服务不可用时仍可本地记账，稍后补充汇率。

App Store 购买

完整版本由 Apple 处理付款，旅序通过 Apple 提供的已验证交易记录判断购买权益，不接收你的银行卡资料，也不建立旅序账户或购买后台。恢复购买仅恢复权益，不上传、恢复或同步本机行程。退款请求由 Apple 处理。

你的选择

你可以不配置 AI、随时移除 API Key、在设置撤回识别授权，或删除本地来源资料与行程。撤回授权会影响之后的扫描，无法撤回已经发送给 DeepSeek 的内容；有关其持有资料的权利请求应依据服务商提供的渠道提出。
