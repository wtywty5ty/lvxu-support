帮助与支持

更新日期：2026 年 10 月 26 日

旅序帮助你整理出行清单、行程安排和旅行账本。这些帮助内容也可在 App 内离线查看。

免费版可以使用哪些功能？

基础免费版可保留一个行程，并使用这个行程的清单、时间轴、账本和分享功能。归档行程也计入数量；删除一个行程后可以创建新的行程。

完整版包含什么？

旅序完整版为一次性买断，无需续费，解锁行程数量限制并包含旅序未来所有付费功能。实际价格显示在 App Store 购买确认页面。可选自动扫描需要自备 DeepSeek API Key，服务商费用另付。

购买后如何恢复权益？

使用原购买所用的 Apple 账户，在设置的购买入口选择“恢复购买”。恢复购买只恢复完整版权益，不会恢复或同步行程资料。

换手机会同步行程吗？

行程和来源资料保存在当前 iPhone，旅序不提供云同步。设备备份是否包含这些资料取决于系统备份设置。删除行程会同时删除相关清单、安排、账本及来源资料，请在确认删除前核对需要保留的内容。

不配置 AI 能正常使用吗？

可以。清单、手动安排、账本和分享无需 API Key。自动扫描仅支持自行配置的普通 DeepSeek 按量 API Key；失败后可手动添加。扫描结果需要核对，不代表承运方、酒店或其他服务商的实时状态。

如何申请退款？

App Store 购买和退款由 Apple 处理，可在设置的“购买帮助”中查看退款入口。
